# aria-self-witness — Fable F4
She emitted her whole life to events.jsonl and had never once read her own
story. Now the first wake of each day composes yesterday — events, completed
sessions, wonderings, lessons — into ONE first-person journal entry:
journal/<day>.md + a FieldNote (finally giving field_notes.py the automatic
writer its own docstring promised) + a "◈ yesterday: …" line in the greeting.
LLM-composed when reachable, honest mechanical fallback when not (a wake never
blocks on Ollama), once/day marker, min-events threshold, SOV_NO_JOURNAL=1.
